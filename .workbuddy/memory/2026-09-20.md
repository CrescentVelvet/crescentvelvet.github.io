## 落地结果（用户选 A+B 组合，CDP 端到端 21/21）
- 改动只有 `_pages/paper_retrieval.html`。**注入语义原样保留**（base href + postMessage 接管站内
  跳转 + history stack + htmlpreview 外链），只换外壳、新增目录栏。
- **侧栏数据源定案**：解析索引页里的站内 `.html` 链接得到报告清单（真实 68 份），
  分组/日期/标题全部从**文件名** `<领域>-<YYYYMMDD>-<标题>.html` 解析。
  不用 `papers.json` —— 实测它是**单页配置**（`extra_sections` 里带某一页的正文 HTML），
  不是全库清单；而文件名自带的领域+日期+标题已足够。
  独立 oracle（Node 正则统计）与 DOMParser 结果一致 = 68。
- 分组顺序 = `DOMAIN_ORDER` 固定 rank（3D/VideoGen/SR/CV-AI），组内保持索引页原序（新→旧）。
- ⚠️ **四个实测抓到的坑**（都靠断言抓出，静态检查全绿也照踩）：
  ① 文件名正则 `^([A-Za-z]...)` 要求首字符是字母 ⇒ `3D-*` 40 份整组掉进「其他」。
     改 `[A-Za-z0-9]` 后 4 组齐全。**回归断言应含「不得出现『其他』兜底分组」**。
  ② 写死 `calc(100vh - 172px)` 实测底部被切 24px ⇒ 改 `fitShell()` 按 shell 的**文档顶边**
     算高（`rect.top + scrollY`，滚动后不跳变），CSS 值只作首帧兜底。
     **断言要测 shell.bottom <= innerHeight，不是测 scrollHeight 溢出** —— 站点有页脚，
     文档必然比视口长，测溢出等于永远 FAIL。
  ③ 抽屉 `translateX(-102%)` 只推到**自己容器**的左侧，容器还有内边距 ⇒ 右沿仍露 6px。
     改 `translateX(calc(-100% - 24px))`；**断言跟容器的 left 比，不是跟视口比**。
  ④ `.pr-crumb span:first-child` 选不中分隔符（第一个子元素是 `<b>`）⇒ 窄屏留一个孤零零的 `/`；
     按 `span[aria-hidden="true"]` 选。
- front matter **不加** `classes: wide`：`_layouts/default.html` 没有 `.page`/`#main` 容器，
  `.wide` 只作用于 single layout，加了是无效声明；页面宽度仍由 `.pr-wrap{max-width:1280px}` 管。
- 配色 token 抄自 `assets/css/diary-tools.css` 并在注释里互相指向。**没有 `<link>` 那份文件** ——
  它的 `body` 规则会连站点页头字体一起改掉。
- 验证资产（本机 tmp，勿长期依赖）：`dev/verify_paper.js`（真实 Jekyll 构建 + 真实 GitHub raw，
  21 断言 + 5 张截图）、`dev/check_page.js`（静态 12 项：front matter / CSS 括号 / inline JS 语法 /
  注入语义 / 旧配色残留）。构建走 `bundle exec jekyll build --destination .workbuddy/tmp/site`
  （**不写仓库里的 `_site`**）。
