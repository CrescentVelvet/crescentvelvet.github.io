# 2026-09-07 工作日志

## 模型对比页面（_pages/splat-compare.html）

### 背景
峰哥要在 GitHub Pages 站点加一个高斯泼溅 PLY 模型对比查看器，用于消融实验对比多个模型。

### 技术选型（经 grill-me 技能多轮决策确定）
- **渲染库**：three.js + GaussianSplats3D（`@mkkellogg/gaussian-splats-3d` v0.4.7）
- **加载方式**：纯 `<script type="module">` + import map，库文件下载到 `assets/js/vendor/` 本地引用
- **不用 supersplat-viewer**：它设计为单实例，多窗口相机联动要 hack，不如 three.js 原生多 renderer 方便

### 实现要点
- **多窗口布局**：CSS Grid，2→1×2 / 3→1×3 / 4→2×2 自适应，固定等分，细 gap + 暗色背景
- **相机联动**：完全联动，同步轨道角(azimuth/elevation) + 相对距离比例 + target；每个模型按包围盒归一化到统一虚拟尺寸(4单位)；用 OrbitControls 的 change 事件广播，syncLock 防循环
- **GaussianSplats3D 用法**：`selfDrivenMode:false` + 自定义 renderer/camera/`useBuiltInControls:false`，自己跑渲染循环；OrbitControls 从库直接 export 使用
- **交互**：整页拖拽 + 文件选择按钮，每窗口独立 loading spinner+进度条，标题栏可编辑+关闭按钮，首个加载完自动 fit all

### 重要坑：assets/js/vendor 被 _config.yml exclude
minimal-mistakes 主题的 `_config.yml` 第 141 行 `exclude:` 列表里有 `assets/js/vendor`，
导致放这个目录的 JS 文件不会被 Jekyll 复制到 _site，浏览器请求返回 text/html（404页），
表现为 module 脚本加载失败、事件监听不注册、拖拽文件直接被浏览器打开。
**解决方案**：库文件改放 `assets/splat-vendor/`（不在 exclude 列表），正常作为静态资源服务。

### 重要坑：GaussianSplats3D v0.4.7 真实 API（非臆测）
- `viewer.getSplatMesh()` ✅ 存在，返回 SplatMesh（继承自 THREE.Mesh）
- `splatMesh.getScene(0)` ✅ 存在，返回 SplatScene（继承自 THREE.Object3D）
- `scene.splatBuffer` ✅ 有 `sceneCenter` 属性（THREE.Vector3）
- `scene.position` / `scene.scale` / `scene.quaternion` ✅ 直接设即可做 transform
- ❌ `splatMesh.getBoundingBox()` 不存在
- ❌ `splatMesh.setScaleAndOffset()` 不存在
- 归一化方案：加载后 `scene0.position.copy(sceneCenter).multiplyScalar(-1)` 把中心移到原点，
  相机 target 统一用 (0,0,0)，联动只同步球面坐标 azimuth/elevation/distance
- Viewer 无自动 fit 方法，初始视角需手动设（距离3/俯角60°/方位45°）

### 重要坑：three.js v0.185.1 模块拆分
`three.module.js` 内部用相对路径 `import {...} from './three.core.js'` 拆成两个文件，
只下载入口 `three.module.js` 不够，必须同时下载 `three.core.js`，否则浏览器报 404。
unpkg 路径：`https://unpkg.com/three@0.185.1/build/three.core.js`（1.4MB）。
排查方法：看 three.module.js 第 6-7 行的相对 import 语句。

### 重要坑：blob URL 无法被 sceneFormatFromPath 识别
GaussianSplats3D 的 `addSplatScene` 默认用 `sceneFormatFromPath(path)` 从路径后缀推断格式，
blob URL（`blob:http://...`）无扩展名 → 推断返回 null → 报 "File format not supported"。
**解决方案**：`addSplatScene` 的 options 里显式传 `format: SceneFormat.Ply`（值为 2），
并从库 import `SceneFormat`。源码位置：gaussian-splats-3d.module.js 第 12968 行。

### 重要坑：SharedArrayBuffer 需要 crossOriginIsolated
GaussianSplats3D 默认 `sharedMemoryForWorkers: true`，用 SharedArrayBuffer 在主线程和
sort Worker 间通信，要求页面 `self.crossOriginIsolated === true`，需要服务器发两个头：
- `Cross-Origin-Opener-Policy: same-origin`
- `Cross-Origin-Embedder-Policy: require-corp`
Jekyll/GitHub Pages 默认不发这俩头 → `postMessage` 传 SharedArrayBuffer 抛 DataCloneError。
**解决方案**：Viewer 构造时传 `sharedMemoryForWorkers: false`，改用普通 transferable，
性能略降但无需特殊 HTTP 头。源码位置：gaussian-splats-3d.module.js 第 12316 行。
注意：GitHub Pages 生产环境也不发 COOP/COEP 头，所以必须用 false。
