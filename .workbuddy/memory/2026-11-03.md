## 48.17–60s 梦窗段：我接手重做（同日晚）

峰哥把这段交回来，三条要求：**门做成"一扇扇次第打开、主体向前穿过"**、**两侧光柱太杂要删**、
**白光要"扩散到全屏再淡淡消失"、要有光的质感（圆形渐变），不能是一坨白面团**。

### 白光：`luWhiteFlood(c,cx,cy,R,bright,top,bt,t)` 重写

关键是把"范围"和"亮度"拆成两个独立参数，并让墨量分档连续：

- `cov = clamp01((1 - r/R) * 1.5)`，`r = hypot((x-cx)/59.5, (y-my)/hh)`，`hh = (bt-top)*0.425`。
  1.5 的增益让中心迅速饱和成实白，只有最后一圈才转灰——中间留一大片"均匀灰"会被读成雾/纱窗。
- `v = cov * bright * edge`（`edge` 是上下各 4 行的软边，光不硬切在场景带边界上）。
- 墨量按 `v` 分档：`<0.22` 按概率抽样 `·`；`<0.42` `░`；`<0.62` `▒`；`<0.82` `▓`；否则 `█`，**全部只用白色 W**
  —— 不掺金色/暗色，所以不会出现"同心色环"。
- **`bright` 是亮度包络（0..1），不是半径**：降 bright 时整屏按比例降档、覆盖范围不变 ⇒ 这才是"淡淡消失"；
  早期版本把 bright 乘在半径上，淡出会变成"光团缩小"。断言里专门测了这条（见下）。
- `R` 上限 1.45（左右到边、四角留暗角，像真实镜头进光），`hh` 收窄后纵向也有圆形渐变而不是被裁边填满。

### 门：`luDreamPortal(c,cx,cy,p,t,index)` 重写

- 所有门共用同一条地平线 `floor = cy+13`，靠 `H = 26*s` 越长越高表达远近 ⇒ 读起来是一排门立在走廊里。
  `s = 0.18 * 11^p`（指数增长＝匀速前进的透视），`s>4.2` 直接 return（已贴脸出画）。
- 形制：门槛 + 两根门柱 + 尖拱（拱用 `╱╲` 全角斜线，锯齿感弱于 `/`），近处才加门楣 `◆`。
- 门板：**每 2 列一条竖栅**（`│`，G/K 暗金），顶边跟着拱形走（按列插值），不整面填色——整面会读成一堵墙。
  开合 `open=(p-0.60)/0.25`，即"贴近时才从中缝裂开"，中缝两侧压亮线才看得出"门在打开"。
- 亮度分档 `p>0.85?G : p>0.62?N : p>0.30?G : K`，贴脸那层降一档，避免两根孤柱变成荧光棒。

## 48.17–60s 梦窗段第四次：自查后二次返工（当晚）

v1 自己录完拼图一看就发现两个硬伤，没敢直接交：

- **门仍是"铁栅/帐篷"**：三层门各画 13 列竖栅，三层叠在一起 ⇒ 一排栏杆；尖拱是直边三角形，
  在字符网格上读成"尖顶小房子"；`s` 上限只到 1.98（`halfW` 最大 25 字符），门永远出不了画 ⇒ 没有"穿过"。
- **白光还是扁椭圆**：`R` 峰值 1.45 < 四角对角半径 1.544，四角恒暗 ⇒ 画面中央一个白眼。

改法（三次迭代，全部实拍比对）：

1. **门的尺寸映射**：`s = 0.22 * 13^p`（0.22→2.86），三层级差 `13^(1/3)=2.35` 倍。
   `halfW = 17s`、`H = 22s`；`floor = cy+13+8p²`（**地平线下沉**：门槛从脚下扫出画外，
   最近那层才不会在 `p→1` 时"啪"地消失）。
2. **拱顶改半圆**：逐列取椭圆上的点 `y = springY - archRy*sqrt(1-tx²)`（`archRy = 0.38H`），
   用整格字符连成弧。直边三角拱 = 尖顶房子，弧线才读成门洞。试过 `halfW=15s/H=30s`（太窄，
   像帐篷）与 `24s/22s`（太宽，像屋顶），最终 `17s/22s`。
3. **窗棂只在"能看全"时画**：`p<0.42` 只留轮廓（远处三层窗棂叠一起就是铁栅）；
   `springY-archRy<5`（拱顶已顶出画外）也撤掉窗棂 —— 这时人已在门洞里，只该看见门框扫过去。
   窗棂＝一条中竖 + 两条横档（六格），有棂才读成"窗"。
4. **白光 `R` 峰值 1.45 → 3.20**：越过四角对角半径 1.544 后继续长，峰值时四角也到 ▓，
   四边就是光的边界，不再是悬在中间的扁椭圆。
5. **白光淡出改"覆盖率溶解"**：墨量档位与覆盖率都由 `v` 决定，
   `den = clamp01(v*1.9)`，`den<1` 时按 `hash16` 采样漏格。降 `bright` 时整屏一边变淡一边漏格，
   后面的火焰从缝里显影 —— 而不是罩一层灰纱把下一镜盖死。
6. 时间轴：`flood=(e-5.25)/1.45`（53.4s 起长，54.8s 铺满，55.17 稳定，55.2→55.7 淡完）；
   meet 段 `if(e<1.05) fade=(1-k)^1.3`。实测平均亮度：峰值 162.7 维持 54.84–55.17（0.33s），
   55.34 落 105、55.59 落 60（≈黑）。删掉 `luTunnelGlow`（死代码，小光核与远处小门重复）。

验证：语法 PASS；`check_dream2.cjs` 加到 **80 断言**全过（掩码改成按 `R=3.20` 峰值实测：
`full total 3077 / solid 2760 / corner 114`，`dim total 2436 / solid 0 / corner 57` —— 淡出是整屏降档）；
全曲 E2E **25/25**；录制 `errors=0`。

踩坑：① 掩码断言的 `R` 常量没跟着峰值改，还在测 1.45 的旧形状；② "四角该不该亮"的断言口径反了
（原来测"四角滞后"，现在设计要"四角也亮"）；③ 交接断言 `sdiff≤10` 因为覆盖率采样翻档变成 15，
改成"核心区（|dx|≤28,|dy|≤7）零差 + 全画幅 ≤40"。
