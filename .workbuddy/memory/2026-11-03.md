## 48.17–60s 梦窗段：我接手重做（同日晚）

### 白光：`luWhiteFlood(c,cx,cy,R,bright,top,bt,t)` 重写

关键是把"范围"和"亮度"拆成两个独立参数，并让墨量分档连续：

- `cov = clamp01((1 - r/R) * 1.5)`，`r = hypot((x-cx)/59.5, (y-my)/hh)`，`hh = (bt-top)*0.425`。
  1.5 的增益让中心迅速饱和成实白，只有最后一圈才转灰——中间留一大片"均匀灰"会被读成雾/纱窗。
- `v = cov * bright * edge`（`edge` 是上下各 4 行的软边，光不硬切在场景带边界上）。
- 墨量按 `v` 分档：`<0.22` 按概率抽样 `·`；`<0.42` `░`；`<0.62` `▒`；`<0.82` `▓`；否则 `█`，**全部只用白色 W**
  —— 不掺金色/暗色，所以不会出现"同心色环"。
- **`bright` 是亮度包络（0..1），不是半径**：降 bright 时整屏按比例降档、覆盖范围不变 ⇒ 这才是"淡淡消失"；
  早期版本把 bright 乘在半径上，淡出会变成"光团缩小"。断言里专门测了这条（见下）。
- `R` 上限 1.45（左右到边、四角留暗角，像真实镜头进光），`hh` 收窄后纵向也有圆形渐变而不是被裁边填满。

### 门：`luDreamPortal(c,cx,cy,p,t,index)` 重写

### 门板：红门 + 双开

### 白光：三个根因

1. **形状是扁椭圆**——`hh=max(6,(bt-top)*0.425)≈11.9` 行，横向却铺到 `hw=59.5` 列。
   字符格 1 列×2 行，视觉半径相等要求 `hh=hw/2≈29.75`。原来的取值把圆**压扁了 2.5 倍**，
   这才是"一直是个扁椭圆"的真正原因（之前一直调 R 和亮度的方向是错的）。改 `hh=hw*0.5` 后，
   R=1 的光斑正好横到左右边、纵向溢出上下边 ⇒ 读成圆。
2. **上下各留 4 行暗带**——`edge` 从 `(y-top)/4` 线性到 0，峰值时最上 4 行从黑渐变到亮，
   整团读成"悬在中间的椭圆"。改成只软 1 行且下限 0.90（`mix(0.90,1,(y-top)/2)`）。
3. **铺满时间太短**——原来满屏只有 0.26s。`flood` 起点 5.25→4.70、峰值 R 3.20→3.00。
   实测四角亮度 217.5/220.2（接近最亮），满屏 53.87→55.20 约 1.33s。

### 淡出：不能抽样

⚠️ **整屏低亮度不能靠随机漏格**。淡出时整屏 v 相同，`den=clamp01(v*1.9)` 在 v≈0.1 时只画
19% 的格子，看到的是一屏**电视雪花**（第一版就是这样）。改法：给 `luWhiteFlood` 加
`hard` 参数，淡出走"整屏同步降档"，只有最后一档 `░` 用 `Math.pow(v/0.22,1.6)` 收尾。

⚠️ **淡出指数要取 0.7 不是 >1**。`Math.pow(1-k,1.25)` 会让低亮度区拖到 3~4 帧，
每帧都是满屏灰网格。取 0.7 后 `░` 全画区只占 0.115s（约 1.4 帧），噪点区不到半帧。
总时长也从 1.05s 收到 0.62s。

## 48.17–60s 第四轮：光从门缝里长出来 + 块状噪声蒸发

峰哥两点：**白光要从门缝里扩散出来，位置不对**；**整屏白光散去可以用抽样，不要整屏一起变淡**。

### 起点：细线 → 竖缝 → 张开（三段）

旧版一律 `R` 从 0.10 涨到 3.00、横向不压缩 ⇒ 画面正中冒出一个小圆点，"凭空一团白"。
现在 `luWhiteFlood` 加 `narrow`（横向压缩）参数，起点 `narrow=0.11` ⇒ 横向 6 列、纵向靠 `R` 撑到门洞高。

三段推进（`flood∈[0,1]`）：
```
grow  = clamp01(flood/0.28)          细线 → 竖缝（0.39s）
Rw    = mix(0.14,0.50,grow^0.60) + 2.50*bloom²
nw    = mix(0.11,1,bloom^1.60)       bloom=clamp01((flood-0.26)/0.74)
```
- ⚠️ **`R` 直接给 0.50 会让竖缝"啪"地出现**。必须 `grow` 从 0.14 长上来，前 0.39s 是
  "一道细线在门里慢慢拉高"，才像光在往外渗。
- ⚠️ **光心必须传进函数，不能再用 `(top+bt)/2`**。旧代码 `cy` 收下了却没用（写成

### 散去：块状值噪声抽样，不是整屏降亮

上一版为了躲"电视雪花"改成整屏同步降档——峰哥不要，要抽样。

⚠️ **逐格 `hash16(x,y)` 抽样 = 满天星**，所以用**两级平滑噪声**：

```js
function luBlockNoise(x,y,cs,cy,seed)   // 块 cs×cy，块间 smoothstep 双线性
h = luBlockNoise(x,y,9,6,0)*0.62 + luBlockNoise(x,y,4,3,977)*0.38
```

- 大块 9×6 决定"整片塌陷"的范围，小块 4×3 在边界啃碎屑。
- ⚠️ **两级用加权平均会让边界糊成均匀噪点**，试过 `h1*0.42+h2*0.58`，整屏变成规整马赛克方阵；
  必须"大块主导 + 小块小幅调制"或直接用双线性插值（后者效果最好，边界有弧度）。
- ⚠️ **块尺寸要按"视觉正方"取**：1 列=1、1 行=2 ⇒ 宽:高 = 2:1。取 3×2 会变成一条条横纹。

- ⚠️ **不要再"降档到 ░/▒"过渡**：试过 `gap<0.13 → v=0.48`，白底上立刻浮出一层灰网格，
  整屏读成"纱窗"。白 → 消失两跳最干净（字符 █ 本身铺满时也有字缝网格，加灰档会放大它）。
- 曲线用**线性** `k`（1.05s）。试过 `k^1.35`：前 0.4s 几乎不动、后段突然塌，节奏断裂。

## 48.17–60s 第五轮：淡出改成"逐级降档"再消失

峰哥：**块状抽样保留，但每格要从 █→▓→▒→░→· 逐渐变淡消失，不是一下子消失；总时长不变。**

上一版是硬切：`if(h<dissolve*...) continue;` —— 某块一旦被抽中就整块瞬间消失，
所以画面上是"白屏上被抠掉一块"。改成**给每块一个消失时刻 t1，在 t1 前 0.55 的窗口里
把亮度线性压到 0**，v 是档位的唯一输入，于是自然走完 5 档。

```js
var sidx=clamp01((h-0.22)/0.56);          // 噪声挤在 0.5 附近，先拉平到 0..1
var t1=0.55+sidx*(1.0+0.40*v)/1.40*0.45;  // 消失时刻∈[0.55,1]，窗口 0.55
var pr=clamp01((dissolve-t1+0.55)/0.55);  // 0=满档，1=已散尽
if(pr>0)v*=(1-pr);
```

⚠️ **t1 下限必须 ≥ 窗口宽度**（0.55），否则 `dissolve=0` 时就有块 pr>0 ⇒ 淡出第 0 帧
已经不是满白，和上一镜的满白交接会裂开。

⚠️ **最淡档要允许 '·'**。原来 `v<0.22` 一律给 '░' 并逐格抽样 ⇒ 序列只有 █▓▒░░░ 没有 '·'，
两端还被打成散点。改成 `ch = v<0.11?'·':'░'`，且**溶解时关掉逐格抽样**（随机性已由块噪声
提供，再抽一次就是之前那版"雪花"）。

⚠️ **块尺寸与窗口要一起调**。首版 9×6 / 4×3、窗口 0.45，单帧掉一档但抽样拼图上像"霉斑"：
块太小 ⇒ 同一时刻既有刚起步的块也有已散尽的块，空间上不连续。改成 12×8 / 5×3（权重
0.72/0.28）+ 窗口 0.55 后，灰阶层次铺得开，`ds=0.55` 时 `tiers={█:0,▓:882,▒:993,░:1223,·:177}`
—— 整屏都降了一档以上，但深浅不齐，读成"光在一块块变淡"。

### 断言口径重写

旧断言 `diss.total<full.total*0.72` 在新语义下必然失败（渐隐不会让格子数大幅下降）。

## 第七轮 · 誓约盾分镜（64.40–68.09）整段重做

按"厚涂 + 块状抽样"的既定口径往下推一段：`lu_s4_oath` / `luOathSequence` / `luOathShield` /

⚠️ 与之前 `var W=15*s` 遮蔽白色常量是同一类事故：**局部变量名必须避开 top/bt/W 这类被参数或全局占用的名字**。

### 根因 2：老盾是 5 段多边形拼的椭圆 + 中央一团大火

`[[0,-10],[19,-7],[23,-1],[19,7],[0,13]]` 镜像成椭圆，中央再叠一团 `size≈1.0` 的火焰，
缩略图里就是一个"红心/番茄中间插一束白光"。改成**塔盾宽度函数**逐行扫描：

```js

  if(u<0.20)return 8+12*Math.sin(u/0.20*Math.PI/2); // 椭圆顶，与竖直肩线相切
  if(u<0.52)return 20-1.2*((u-0.20)/0.32);          // 上身近乎垂直（塔盾的肩膀是直的）

```

`diag = v + side*d*0.55 + sin(t*1.5)*2.2 + sin(v*1.7+side*d*0.9)*1.3`，按 `diag` 分四档
`█R / ▓R / ▒R / ▓G`。要点：
- **横平竖直分档会读成三条竖条纹**，必须沿对角切；
- 只有三个低频阈值时，分界是一条笔直的暗带，像贴了块补丁 ⇒ 叠高频扰动打散；
- 最暗一档**不能用 `░R`**：纯黑底上的稀红点会整块消失，盾右下角像被啃掉 ⇒ 换 `▓G`（暗棕阴影）。

### 进场：火焰从中央裂开，而不是从下往上擦

老写法是 `edge=bt-age/0.75*(bt-top)` 整幅向上擦除，火焰会残留在上方和盾顶叠着，
读成"两层画面"。改成裂缝半径**跟着盾的当前宽度走**：

```js
var shHalf=20*mix(0.07,1,Math.pow(clamp01(close/0.55),0.70));
var seamR=shHalf>2?shHalf*1.2+4:0;
seamR=Math.max(seamR, Math.max(0,(age-0.45)/0.45)*(cx+8));
```

⚠️ 两个坑：① 高度 `gh` 原来写成 `((close-0.22)/0.78)`，前 0.22 段高度是 0，
宽度却已十几格 ⇒ 中间被压成一条横线，画面读作"空了一片黑"；宽高必须同时起步。
② 裂缝不能按时间自己走（`age/0.66`），必须跟盾宽绑定，否则火焰已经让开、盾还没长出来。

### 撞击：从"几个斜线点"改成能看见重量的三下

原来碎片 3 格、0.22s 冲 39 格（12fps 下每帧跳 15 格），只剩斜线在闪。现在：
- 4 片、从 `cx±54` 出发、飞行 0.30s，带 3 段拖尾，命中后**边飞边缩**（`sc=1-(aa-cut)*2.2`），
  否则段尾还有大三角挂在石壁上像补丁；
- 命中瞬间在命中点炸一圈白热十字 + 金环；

## 第八轮 · 呼唤/熔流聚拢分镜（68.09–72.01）重做

`█R / ▓R / ▒R` 三档红在 6px 的格子上几乎同色，整面盾摊成一块平红布。暗面直接给暗棕

### 白热柱：直轮廓 = 建筑

3. 顶部 30% 逐格掷骰开口 → 城垛；

### 柱锤：从"悬空的发光牌子"到机械锻锤

旧版是一根**等宽通高、内部塞满 `◆` 铭纹的方柱**，外面还套两道细竖线 —— 缩略图里

- 高光只给左上角 2–3 行的一小条（整条通高白带会让锤头读成"一本书的书脊"）；

### 冲击：0.07s 的细线 12fps 抓不到

原来只有 `if(d4<0.07) c.line(...,'█',W)` 一行，12fps 下连一帧都抓不到，落锤读不出"砸到了"。
现在 0–0.14s：砧面横贯 `█W` + 26 根星芒放射；抖动 `exp(-dt*7)*(2.6+hit*0.7)`
（原来是 `exp(-dt*10)*1.7`，12fps 下第一帧就衰到不足 1 格）。

### 冲击环：完整椭圆 → 沿砧面外推的地面冲击波

画完整椭圆时 r 跑到 44，上下两个极点被拉成两条**横贯全屏的点线**，像扫描线。
改成"两道对称横线边跑边抬"（`py=24-u²*5`），r 封在 30。

### 双环：五个版本的形状问题

1. 等高并排 + `sep` 太小 → 两个下弧连成一条下凹曲线，读成**一只碗/托盘**；
2. 收小 sep 到 8 / rx 到 11 → 两条底弧分开，但又成了**蝴蝶酥/眼镜**；
3. `cy` 从 22.5 走到 19.6 → 环的下弧一直压在砧面那条亮带上，糊成一条厚底；
   ⇒ **底边钉在砧面上方（`cy=22.6-ry`），环是往上长出来的**；
4. 两环等高 → 上下弧在同一行对齐；⇒ **错开两行**（右环 `cy-1`、左环 `cy+1`），
   立刻有"一环穿过另一环"的纵深；
5. 最暗一档给 `▒B`（25% 网点）→ 缩略图里右半个环像断了 ⇒ 最暗也要 `▓`。

穿扣靠**交替断开**：上交叉点让右环连续（左环 skip）、下交叉点让左环连续（右环 skip）。
旧版按"上/下半圈"排序重绘四段弧，结果中间糊成一坨。

### ⚠️ 逐格 hash 溶解 = 砧面上撒了把沙

金带散开时用 `hash16(...)%100>fade*100` 逐格消失，散成一片碎点，看着像撒了沙子。
