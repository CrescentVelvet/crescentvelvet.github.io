⚠️ **两个可复用的坑**
1. 手写 Fruchterman-Reingold **必须每轮把坐标夹紧在画布内**：零度节点只受斥力，
   会把包围盒撑到几倍大，之后线性归一化会把其余 57 个节点挤成中间一个小点。
2. **SVG 标签估宽不能用「字符数 × 常数」**：CJK 字形约 1em、拉丁约 0.55em。
   按 0.62em 常数估，中文标签会被算窄 15%+，越界检查放行后直接溢出画布
   （实测 `同事方案MHR高斯数字人 · 被引 7` 被切掉）。

### 分支 B 取证数字（`.workbuddy/tmp/grill/branchb.js`）

| 口径 | 数值 |
|---|---|
| 入度分布 | `in=0 → 23 篇` / in=1 → 10 / in=2–3 → 18 / in=4+ → 22 |
| 只用互链时的空面板 | **23 篇零反链（31.5%）**、38 篇零出链（52%）、16 篇「入出皆零」 |
| 加「同主题」后 | 入出皆零 **+ 无主题邻居 = 只剩 1 篇**（`CV-AI-20260813-用AI做论文调研经验分享`，topics 为空） |
| 邻居规模（中位/p75/max） | 「同主题」10 / 13 / 27 · 「同标签」**1 / 3 / 9**（p25 = 0） |
| 边规模（无向去重） | 互链 188 · 同主题 378 · 同标签 70 |

**两条结论**
1. **tags 不能当边**：362 个唯一标签、长尾，邻居中位数只有 1、p25 为 0 ⇒ 边又稀又噪。
2. **topics 不能当主图**：同一 topic 天然成团（`视频生成模型谱系` 14 篇 = 完全图），
   画出来是一块无结构的饼；但作为**兜底邻居列表**极好（把空面板从 16 篇压到 1 篇）。
3. 出链**运行时零成本**（`fetchDoc` 已把正文 `text` 拿在手上，解析即可）；
   反链必须预计算（索引页卡片里没有笔记间链接）。
