## 算法框图（_pages/flow_chart.html）：按 paper-framework-figure-studio-pro 规范重构
- 参照源：`github.com/c-narcissus/paper-framework-figure-studio-pro` v3.2.15f（zip 内 `references/*.md` 规范文本，只读未安装）。核心口径：line-art schematic（无衬线标注 / 白底 / 细线）、分组用 containment 而非装饰虚线、虚线一族一义且必带标签、edge-label-first（变量写线上不套框）、图内只留短模块名（定义进图注）、灰度下可读（形状承载语义、颜色只作亮度冗余）。
- ⚠️ 修正当日定案：**图内标注由衬线改为无衬线**（Nature/IEEE 建议 Helvetica/Arial 类；技能规范明确要求 sans）⇒ `FIG_FONT` / `--font-fig` 改为 Arial→Helvetica→PingFang→Hiragino→YaHei 栈；`getTextMeasureCtx()` 同步 12px（上一条的测量一致性坑仍适用）。
- 上一轮被截断的响应已落盘「声明层」（分组/图注的 CSS+HTML 骨架、正交折线 elbow 路由、24px 网格吸附 `snapTo(v, free)`、`inkMode` 线稿开关），JS 实现缺失 ⇒ 本轮补齐。**教训：响应被截断 ≠ 改动未落盘，继续前先 `git status --porcelain` + 对照 diff 摸清真实基线**。
- 新实现（画布与导出共用）：`state.groups`（模块分组容器，细实线边界 + `(A)/(B)/(C)` 字母标签 + 组名，GROUP_PAD=20 内边距）、拖框创建 / 拖右下角手柄改尺寸 / 移动 / 面板改名；`state.capNo+capText`（图注，`renderCaption()` 贴图下方、编号 tspan 加粗、按测量折行）；`runSpecCheck()`（7 条硬门禁清单进右侧面板：虚点线带标签 / 语义族≤2 / 分组非空 / 边标签≤16 字 / 节点≤3 行 / 无孤立节点 / 图注非空）；`btn-ink` 线稿↔彩色切换。
- 导出 `buildExportSVG()`：分组画最底层、图注贴底、根 `font-family` 用 `EXPORT_FONT`（FIG_FONT 双引号→单引号）；边界 = nodes+groups+conns+图注高度；`fitContent()` 也把图注高度计入。
