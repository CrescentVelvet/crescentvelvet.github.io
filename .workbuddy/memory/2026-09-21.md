## 待办清单页面：加口令加密（`_pages/todo_list.html`）

**起因**：峰哥问要不要给 todo_list 加密。核查后确认：仓库 `CrescentVelvet/crescentvelvet.github.io`
是 **public**（API 实测 `"private": false`），`raw.githubusercontent.com/.../assets/data/todo_list.json`
无需登录即可读到全文，内容含公司内部项目名与进度（HYPIR / VGGT-Omega / MiniMaxH3 / PDF-Gaussian）、
具体问题细节、任职资格申请，以及居住信息（租孖岭 / 租雅宝 / 深圳出差入住酒店）。
⇒ 加密不是可选优化，是必须做。

**三条定案（别回退）**
1. 复用 `assets/js/diary-crypto.js`（AES-256-GCM + PBKDF2-HMAC-SHA256 60 万迭代），**与日志共用同一个
   `assets/data/key.envelope`** —— 峰哥只需记一个口令。
2. 数据文件：密文 `assets/data/todo_list.enc`（单行 `DIARYENC1:iv:ct`）；明文 `todo_list.json`
   退出 git 跟踪（本地保留，便于直接编辑与本地预览）。
3. **明文模式故意不加锁** —— 内容本来已公网可读，加锁是安全剧场；只在顶部出警示条 + 「加密迁移」按钮。
   加密模式才给整页遮罩。

**实现要点**
- `boot()`：先 GET `todo_list.enc` → 200 进加密模式（`body.locked` + 遮罩，**解锁前不渲染任何节点**）；
  404 回退明文 json 并显示警示条。**这个 404 是「无密文」的设计信号，不是缺陷**，回归测试须放行。
- 解锁：`openEnvelope(口令, envelope)` → DEK（只驻内存，不写任何存储）→ `decryptData` 解正文。
- 导出按模式分流：加密模式出 `.enc`（主）+「导出明文备份」（次）；明文模式出 json。
- 顺带修掉过期文案：底部提示原写死「导出 JSON 下载覆盖 todo_list.json」，现按模式动态指向 `.enc` / `.json`。

**⚠️ 关键坑**：页面「加密迁移」导出的是**页面当前渲染的数据**，而线上 `todo_list.json` 可能落后于本地
未提交改动（此文件长期脏）⇒ 会静默丢新任务。故另写 `tools/encrypt_todo.js`：直接读磁盘权威文件，
加密后**解密回读与原文逐字比对**才落盘。支持 `TODO_ENVELOPE` / `TODO_PLAIN` / `TODO_ENC_OUT` 覆盖路径
（为了能用测试信封端到端验证）、`--dry` 只校验口令、非 TTY 时从管道读口令。

**验证**
- `.workbuddy/tmp/todo_enc_e2e.js`：CDP 直驱 Edge，27 断言，canary 假数据（真实清单不进测试）。
  三链路 —— 加密模式（未解锁气泡数 0 / DOM 无任务文本 / 错口令被拒 / 正确口令渲染 / 导出的密文在
  Node 侧独立解密比对）、明文回退、两文件皆缺的优雅降级。
- `.workbuddy/tmp/test_encrypt_tool.js`：8 断言（`--dry`、错口令、CRLF 不被改写、缺文件报错）。
- 踩坑：Google Fonts 外链必须 `Network.setBlockedURLs` 断掉，否则无网络时 `readyState` 卡在 loading，
  「零异常」变成假通过。

**未做**：git 历史里的明文未清理（峰哥选「只保护未来」）。如需追溯清除则要重写历史 + 强推，另议。

## 状态语义统计（为「是否加第四态：放弃」取证）

- 方法：`.workbuddy/tmp/stat_todo_status.js` 读 `HEAD~2:assets/data/todo_list.json`（HEAD 已无明文）。
  ⚠️ 局限：那是**上次提交版**，比峰哥当前实际清单旧（他有一批改动从未提交，密文明文比它多 1756 字节）。

  ⇒ `done` 目前同时承担「动作做完了」与「问题解决了」两个语义，状态已被污染。

## 第四态「已放弃」dropped（按上节取证落地）

- **定案（峰哥选定）**：**仅叶子**、**可逆**（非终态）、中文名「已放弃」。
  **明确不做**：父节点状态 —— 父子状态联动规则未定义，属独立设计。
- 实现只动几处：`STATUS` 表加 `dropped` / `:root` 加 `--dropped` / 图例加一项 / `<select>` 加 option，
  加 CSS `.node.leaf.dropped > .bubble`（`fill:#fff` + 虚线描边）+ `.lbl`（深灰 + 删除线）。
  `cleanNode` 的 `if (n.status && isLeaf(n))` 自动兼容，无需改导出逻辑。
- ⚠️ **关键设计判断：用形状（空心 vs 实心）区分，而不是色相。** 三套候选实测对比后否掉两个：
  实心暗红（#b91c1c）与 done 的绿（#16a34a）正好落在**红绿色盲最难区分**的轴上；
  实心暗紫（#6d5b8f）会与**父节点按深度渐变的紫端**（#8B4513→#FF00FF）撞色（单层测试树里看不出来）。
- 回归 `.workbuddy/tmp/todo_enc_e2e.js` 扩到 **33 断言**：图例/下拉各 4 项、dropped 渲染、
  **形状差异断言**（非「非零即过」，比对 done 与 dropped 各自的 fill/stroke）、
  A23–A26 用**真实鼠标点击 + change 事件**跑通 `done → dropped → todo → done` 可逆链、导出保留 dropped。
