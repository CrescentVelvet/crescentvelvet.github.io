## 50–60s 返工：梦窗穿越 + 白光去方块

- 反馈：梦窗完全没有时空穿梭感；开门后的白光是一个正方形。
- 根因一（白光）：`lu_s3_dreamt` 尾段与 `lu_s3_meet` 开头各有一份同样的
  `lightDist=|x-cx|/60+|y-19|/28; if(lightDist<wash*1.55) put('█',W)`。全画幅该值上限只有
  ≈1.42（0.99+0.43），阈值一旦越过 1.42 就把整个 clip 矩形 `[4,32]×[2,117]` 填满 ⇒ 硬边白方块；
  中途又是 L1 菱形等值线的阶梯边，所以先看到"椭圆"再看到"方块"。meet 段还叠了把上一镜整帧
  放大贴回的 entry zoom，接缝进一步强化方块感。
- 根因二（穿梭）：梦窗只有 `pulse=mod(e/1.55,1)` 让 scale 在 0.48↔1.0 之间呼吸，是原地胀缩，
  没有沿 Z 轴连续推进；柱廊 `x=cx±(13+depth*47)` 固定尺寸、无透视，读起来是一排静止的柱子。
- 改法：新增 `luDreamGate`（远/中/近三档细节，近景只留框与竖棂，可看穿下一层）、`luDreamTunnel`
  （3 层错相 1/3 周期，scale 指数增长 0.055→≈2.3 = 透视匀速，出画后远端重生）、`luTunnelGlow`
  （消失点光核随最近一层穿过呼吸）、`luDreamStreaks`/`luDreamDust`（径向速度线与外流尘埃）；
  `luDreamCorridor` 改成严格透视（屏幕位置 46/q、高度 24/q）；新增 `luWhiteFlood`（归一化半径 R，
  1.0 = 贴住四边；概率场 + 抖动网点 + 低频扰动边缘；R≥1.0 直接整帧过曝；内部临时解除行裁剪让白光
  覆盖整幅画布）；删掉 meet 段的 entry zoom，改两圈拱缘向外掠过。
- 参数：梦窗 3 层 / PER 1.55s；白光 0.08→0.97 长成云团，仅 wash>0.93 才过曝，meet 段 1.1×(1-e/0.95)^1.5 收束。
- 验证：内联 JS 语法 PASS；新增 `check_dream.cjs` 74 断言（白光径向单调、四角滞后于核心、R≥1.0 满屏 4800 格、
  48–64s 两次绘制逐格一致、71.5 万字符全在 ASCII+EXTRA、dreamt 末帧与 meet 首帧满白逐格相同）；既有 E2E 25/25；
  三路浏览器错误 0。
