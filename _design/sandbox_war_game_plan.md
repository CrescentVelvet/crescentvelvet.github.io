# 沙盘战争 — 像素风美术设计方案

## 1. 概述

沙盘战争是一个 DOM + CSS 单位、Canvas 地形和 DOM 弹丸组成的前端战场。美术目标是让玩家在缩小的策略地图上，仍能一眼读出阵营、兵种、朝向、载弹量和攻击状态。

本方案沿用现有页面的像素画法：用少量纯色块、1–2px 暗色轮廓、矩形阴影和 `clip-path` 组合出单位，不引入外部图片素材。地图保持低对比度，单位和弹丸承担主要识别度。

## 2. 核心视觉原则

- **像素比例固定**：配件以 1px、2px、3px 的整数块为主，避免细碎抗锯齿；`image-rendering: pixelated` 保持硬边。
- **暗色轮廓优先**：移动物和弹丸始终有深色外轮廓或投影，确保在草地、沙漠、雪地和水面上都可读。
- **颜色只做识别**：友军/敌军色用于队伍和关键状态；车体使用低饱和军绿、钢灰、土黄，避免全屏高饱和。
- **形状先于文字**：兵种靠车体、武器、弹体和尾迹区分；文字只补充状态，不承担主要识别。
- **状态必须可数**：载弹量通过车上实际可见的导弹数量表达，发射后移除对应导弹，不保留假空筒。

## 3. 地图基调

- 舞台底色为深苔绿和深灰绿，内框使用细亮线和暗色投影。
- 32px 战术网格作为统一像素尺度，透明度低于单位轮廓；道路、河流、沙丘、废墟只保留少量方向性纹理。
- 阵营标注改为角落小信息牌，不能使用遮挡中线的大字。
- 地形装饰固定种子生成，重绘、转置和清空后位置稳定。

## 4. 单位 DOM 结构

现有结构保持：

```text
.unit
└── .unit-body              ← 朝向、缩放、暗色投影
    ├── 车体/底盘
    ├── 武器或弹体
    └── 状态配件
```

- `.unit` 和 `.unit-body` 不使用 `overflow: hidden`，保证炮管、翼面、尾焰和抛物线特效可以伸出轮廓。
- 载具的视觉朝向跟随 `--angle`；弹道导弹车和巡航导弹车车体固定朝上，只做平移，导弹和发射特效保持自身朝向语义。
- 单位状态、碰撞、弹药消耗和 DOM 视觉必须使用同一状态源，避免“逻辑已发射、车上仍有弹体”的错觉。

## 5. 导弹车最终造型

### 5.1 弹道导弹车

- **载弹量：3 发。**
- 车上是三枚高松、直立、间距清楚的弹体，弹体直接坐在甲板架上。
- 不使用四联排列、不使用翻盖、不使用箱式舱体；三枚弹体本身就是主要识别符号。
- 弹体使用红白环带、亮色弹头和深色尾部，比例明显高于巡航导弹。
- 发射状态按 `3 → 2 → 1 → 0` 逐枚减少，剩余弹体始终居中，不能出现空筒占位。
- `BallisticMissile` 的视觉重心在弹体高度和厚重底盘，车体不需要额外炮塔或旋转机构。

### 5.2 巡航导弹车

- **载弹量：5 发。**
- 五枚短弹体以斜放或平放方式布置，优先采用两列网格或浅斜列，不能竖直站立。
- 不使用箱式发射箱、不使用旋转托盘；弹体必须直接可见，便于读数。
- 巡航导弹按小型飞机设计：尖头、短机翼、尾部小翼，银灰/青灰配色，和弹道导弹的红白直立轮廓拉开差异。
- 发射状态按 `5 → 4 → 3 → 2 → 1 → 0` 逐枚减少；平放弹体从尾部离架，剩余弹体重新收拢但不补空位。
- `CruiseMissile` 的车体保持固定朝上，导弹本体平飞，视觉上不表现为炮管或垂直火箭。

## 6. 飞行和发射特效

### 6.1 共同锚点规则

- 弹体、烟迹、尾焰必须组成一个局部特效对象，以弹体尾部为唯一锚点。
- 特效对象整体旋转，禁止分别用舞台绝对坐标摆放弹体和烟迹；否则角度变化后烟迹会横切弹体或从弹头喷出。
- 车载发射焰同样从实际弹尾开始，不能从发射架中心统一喷火。

### 6.2 弹道导弹

- **飞行轨迹：抛物线。** 弹体方向跟随当前抛物线的切线，飞行前段上扬，中段接近水平，末段向目标俯冲。
- 烟迹沿切线反方向延伸：尾部到烟迹的第一段必须与弹体轴线重合，后续可用轻微弧线表现历史轨迹。
- 末端加速火焰从俯冲弹体尾部延伸，火焰轴线与俯冲方向相反；火焰可更亮、更长，但不能改变弹体朝向。
- 尾迹使用厚重灰白烟团和暖色火焰，体现大质量、低频、高破坏力。

### 6.3 巡航导弹

- **飞行轨迹：平飞。** 导弹保持近似水平的机头方向，沿直线或少量折线航行，不做抛物线腾跃。
- 烟迹/冷凝尾迹从机尾向后水平延伸，与机翼和机头方向一致；允许在末端俯冲阶段逐渐转向，但不在巡航段抬头。
- 末端加速火焰从机尾喷出，方向与平飞/俯冲切线相反；锁定框位于目标方向，不覆盖弹体尾部。
- 尾迹使用细长青蓝线和少量淡色短段，体现低空、精确制导和飞机式飞行。

## 8. 验收标准

- 默认缩放下能数清弹道车的 3 发和巡航车的 5 发。
- 连续发射后，车上剩余弹体数量与 `ammo` 完全一致。
- 弹道飞行截图中，烟迹第一段与弹体尾部轴线一致，轨迹呈抛物线；巡航飞行截图中，弹体保持平飞，尾迹从机尾水平向后。
- 末端加速时火焰始终从尾部喷出，不能出现在弹头、车体中心或发射架外侧。
- 横屏、竖屏、友军、敌军四种组合下轮廓仍可读；改动单位渲染后必须运行 `heading_harness.js`。
- 不保留四联弹道、翻盖、箱式巡航、旋转托盘等已否决方案。

## 9. 当前定案

最终采用：**三枚高松直立弹体的弹道导弹车 + 五枚斜放/平放飞机式短弹体的巡航导弹车**。弹道导弹走抛物线，巡航导弹走平飞；两者的烟迹、尾焰和车载发射焰都以弹体尾部为锚点。
