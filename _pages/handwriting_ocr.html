使用说明
1. 点击 🔑 填入智谱 API Key（在 bigmodel.cn 创建，新用户有赠送额度）
2. 添加一张或多张手写日志照片，点"开始识别"
3. OCR 精准模式：专攻手写体，逐字纯转录，按上传顺序拼接，最准
4. GLM-4V-Flash：免费视觉模型，流式输出，多图一次识别
5. 结果可编辑，校对后可"复制"或"发送到文本处理工具"继续格式化/加密
⚠ 隐私提示：图片会上传至智谱服务器进行识别；API Key 仅保存在本地浏览器 localStorage。
