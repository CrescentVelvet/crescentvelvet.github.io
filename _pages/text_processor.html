加密导出前需解锁一次。解锁后 DEK 驻留内存，本页所有加密导出 / 导入直接用它， 与 enc_reader / diary_tree 同一把钥匙。口令只解开密钥信封（key.envelope），不接触正文。
📖 新加密怎么用？（与旧版差异 + 完整流程）
  1. 第一步・解锁：输入日志口令点「解锁密钥」。一次解锁，本次打开页面期间有效（刷新/关闭后失效，需重输）。
  2. 加密导出：处理完文本后点「加密导出」——自动按内容里的日期拆分成 YYYY-MM.txt 月文件 + manifest.enc 索引，全部下载后一起放回 assets/data/ 即完成入库。不再需要手动改名 encrypted_log.txt。
  3. 加密导入：点「加密导入」选择 YYYY-MM.txt 月文件——需先解锁，直接解密回输出区，可继续编辑。
  4. 想换口令：去 enc_reader 页面，解锁后点「换口令（重裹信封）」，毫秒级完成。
口令只用于解开密钥信封（PBKDF2 60万次迭代，约 0.5~1 秒），正文用独立的 DEK 数据密钥加密—— 所以换口令毫秒级、解密月文件瞬间完成。口令本身不加密任何正文。
文本处理工具功能说明
1. 段落格式：将文本按行分段，并套用正文排版（宋体 16px / 行高 1.95 / 段距 8px / 首行缩进 2 字，与日志时间轴一致）。
2. 处理日期：对于形如“YYYY-MM-DD HH:MM:SS 用户名(用户ID)”的行，只保留日期部分（YYYY-MM-DD），并移除重复日期；若日期缺失年份，则自动补上当前年份。
3. 去除换行与撤回：删除文本中不必要的空行与撤回信息。
4. 闲情逸致：在包含特定短语的行前添加固定文本。
5. 一键处理全部：按顺序执行所有处理步骤。
6. 复制结果：将处理后的文本复制到剪贴板（会连同排版一起复制，粘进 Word 即为该规格）。
7. 清空：清空输入和输出区域。
8. 站内密钥：加密导出前需解锁一次（与 enc_reader / diary_tree 同一口令）。解锁后导出自动按内容日期拆分为 YYYY-MM.txt 月文件 + manifest.enc 索引，放回 assets/data/ 即完成入库。
